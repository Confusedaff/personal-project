Editor's note on limitations

Editor's note — read before deploying

The multi-agent system adds factual verification on top of the original style-based classifier. However, limitations remain: the ML classifier agent still carries source-style bias (weight: 15%), the fact-check agent requires API keys and internet access, and the media forensics agent's reverse image search is a stub. The credibility list reflects editorial judgment. See docs/limitations.md for the full list.

Treat predictions as a triage signal for human fact-checkers, not an automated takedown mechanism. The orchestrator routes low-confidence or conflicting cases to a human review queue.
