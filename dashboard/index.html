Editor's note on limitations

Editor's note — read before deploying

Reuters wire copy in this corpus almost always opens with a dateline like WASHINGTON (Reuters) — that a classifier can key on instead of learning anything about content. We tested this directly:

Stripping the dateline (and any leftover "Reuters" mentions) removes the biggest shortcut and costs about half a point of accuracy — the residual is attributable to genuine content and style signal, but part of that remaining signal is still Reuters' own house style (formal attribution, weekday-dated reporting, Washington political coverage), not misinformation itself.

A second artifact: every subject tag in this corpus belongs to exactly one class — politicsNews and worldnews are 100% real, the other six tags are 100% fake. The model doesn't use subject as a feature for exactly this reason, but the category breakdown below should be read as "accuracy within a single-class bucket," not a real per-topic difficulty signal. The corpus also skews heavily to political and world-news topics overall. Treat predictions as a triage signal for human fact-checkers, not an automated takedown mechanism. Full write-up: docs/limitations.md.
