# Dataset

This folder should contain the two CSVs from Kaggle's "Fake and Real News
Dataset":

- `Fake.csv`
- `True.csv`

Download them from Kaggle (search "Fake and Real News Dataset", by
Clément Bisaillon) and place both files directly in this `data/` folder.
Columns expected: `title, text, subject, date`.

Not bundled in this download because of file size (~110 MB) and dataset
licensing — grab it directly from Kaggle to make sure you have the
canonical, up-to-date copy.
